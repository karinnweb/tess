# 🎉 Website Ucapan Ulang Tahun

Sebuah website interaktif untuk memberikan ucapan ulang tahun yang menyenangkan dengan efek animasi dan confetti yang indah!

## ✨ Fitur

- 🎈 Animasi balon yang mengambang
- 🎂 Kue dengan lilin yang berpijar
- 🎊 Efek confetti interaktif
- 💬 Ucapan dan doa yang hangat
- 🔊 Suara perayaan (Web Audio API)
- 📱 Responsive design (mobile friendly)
- ✨ Animasi smooth dan modern

## 🚀 Cara Menggunakan

1. Buka file `index.html` di browser
2. Klik tombol "Rayakan Sekarang! 🎈" untuk memicu efek confetti
3. Klik di mana saja di layar untuk membuat efek confetti tambahan
4. Nikmati perayaan digital! 🎉

## 📂 Struktur File

```
tess/
├── index.html      # File HTML utama
├── style.css       # Styling dan animasi
├── script.js       # Logika JavaScript dan confetti
└── README.md       # File dokumentasi (ini)
```

## 🎨 Teknologi yang Digunakan

- **HTML5** - Struktur halaman
- **CSS3** - Styling, gradients, dan animasi
- **JavaScript (ES6+)** - Interaktivitas dan efek confetti
- **Canvas API** - Rendering particles
- **Web Audio API** - Efek suara

## 🎯 Customization

### Mengubah Pesan Ucapan
Edit bagian pesan di `index.html`:
```html
<p class="message">
    Selamat Ulang Tahun untuk Anda!<br>
    Semoga hari ini penuh dengan kebahagiaan,<br>
    Cinta, dan momen-momen yang tak terlupakan.
</p>
```

### Mengubah Warna dan Tema
Edit variabel warna di `style.css`:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Menambah Ucapan Doa
Tambahkan item baru di dalam `<div class="wishes">`:
```html
<p class="wish-item">🌈 Ucapan Anda di sini</p>
```
